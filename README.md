# 📌 Rutas abiertas (sin login)

Estas rutas pueden ser accedidas sin necesidad de autenticación:

## 🔍 Consultas

* **GET /puesto/**
  Permite consultar los puestos libres disponibles.

* **GET /deuda/**
  Permite consultar las deudas registradas.

## 👤 Usuario

* **POST /usuario/**
  Permite crear nuevas credenciales de usuario.

* **POST /usuario/login**
  Permite iniciar sesión (loguearse) en el sistema.

## 📄 Documentación API

* **Swagger UI**
  Accede a la documentación interactiva de la API en:
  http://localhost:8080/swagger-ui/index.html
